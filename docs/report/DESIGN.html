Theme

분위기

습관마다 칸을 사진으로 채우고 한 주와 한 달을 돌아보는 모바일 우선 웹 서비스예요. 흰 바탕 #ffffff, 짙은 글자 #111111, 초록 #13bd7e 하나로 화면을 조용하게 잡아요.

서비스가 칸에 일어난 일만 담담하게 말하는 만큼, 화면도 사진과 경쟁하지 않아요. 초록은 의도적으로 아껴 쓰고, 더 진한 #06a96c는 전폭 주요 버튼에만 써요.

모서리는 역할마다 달라요. 칩 6px, 버튼 16px, 컨테이너 24px예요. 글꼴은 Pretendard 하나만 써요. 이 값들은 뱅크샐러드 레퍼런스에서 측정한 그대로 유지했어요.

Do · Don't

이렇게 쓰고, 이렇게 쓰지 않아요

이렇게 써요

  • accent는 화면당 하나만주요 행동 하나 또는 선택 상태에만 써요.
  • 사진이 색을 담당해요주변 화면은 흰 바탕으로 조용하게 둬요.
  • 안 한 날과 쉬는 날은 중립 톤으로선 #f0f2f5, 글자 #9fa4b0.
  • 굵기는 역할대로읽는 글은 400, 제목과 주요 버튼은 700.
  • 모서리는 역할대로칩 6px, 버튼 16px, 컨테이너 24px.
  • 그림자는 중립색 한 겹타일 보드 위의 칸은 평평하게 둬요.

이렇게 쓰지 않아요

  • accent를 배경이나 칸 채우기에 쓰기장식으로 쓰지 않아요.
  • 빈 칸이나 쉬는 날에 빨강·주황 쓰기탓하는 것처럼 보여요.
  • 옛 값 쓰기#04c584, 2px 모서리, 500 굵기 본문은 쓰지 않아요.
  • 캐러셀 보라·노랑 쓰기레퍼런스 전용 색이에요.
  • 튀는 모션스프링·바운스, 칸이 채워질 때의 축하 연출은 쓰지 않아요.
  • 이모지와 accent 글자만으로 뜻 전하기흰 바탕 대비가 약 2.4:1이라 읽기 어려워요.
