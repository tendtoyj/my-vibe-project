⑤홈타일 보드첫 칸이 채워진 홈 확인 (목표 순간). 하단 [+ 습관 추가] → ②같은 홈이지만 순간이 달라 따로 그림. 습관을 계속 추가할 수 있음

① 로그인—버튼이 눌린 상태로 대기"로그인하지 못했어요. 다시 시도해 주세요."
② 습관 만들기——"습관을 저장하지 못했어요. 다시 시도해 주세요." (이름이 비어 있거나 요일을 하나도 안 골랐으면 [다음]만 비활성, 문구는 없음)
③⑤ 홈습관이 하나도 없을 때 — "습관을 만들면 여기에 칸이 생겨요." / 습관을 만든 직후 — "조깅 띠가 만들어졌어요. 칸을 눌러 사진을 채워요."칸 자리만 옅게 보임"보드를 불러오지 못했어요. 다시 시도해 주세요."
④ 칸 채우기 (시트)—사진 처리 중에는 작은 진행 표시카메라 권한 거부 — "카메라를 열 수 없어요. 사진첩에서 골라 주세요." / 불러오기 실패 — "사진을 불러오지 못했어요. 다시 시도해 주세요." / 저장 실패 — "칸을 저장하지 못했어요. 다시 시도해 주세요."

④시트를 닫음홈에 그대로 머문다

⑤[+ 습관 추가] 탭②로 간다. [다음] 후에는 홈으로 돌아와 새 띠가 아래에 생긴다
첫 버전 범위

첫 버전에 넣음

  • 구글 로그인
  • 습관 만들기(주기별 옵션)
  • 홈의 가로 스크롤 띠(날짜 열 공유)
  • 칸 채우기(사진첩 / 바로 찍기 / 사진 없이 체크만)
  • [+ 습관 추가]

나중에

  • 채운 칸 보기·수정·날짜 수정 (→ F2)
  • 같은 날 여러 장
  • 습관 수정·삭제
  • 알림 켜기·설정·로그아웃 (→ F2)
  • 주간 마무리 (→ F2)

기본값으로 둔 것: 주 N회의 N은 1~6, 기본 3(7회는 매일과 같음). 홈 첫 화면은 오늘 칸이 보이게 스크롤. 사진 날짜가 탭한 칸과 달라도 촬영 날짜를 따름. 계정 화면에 약관·개인정보 동의 한 줄.

변경 기록
  • 2026-10-10 기획 완료.
  • 2026-10-10 흐름 수정: 습관을 만든 뒤 사진 입력까지 묶던 단계를 풀어, 습관 만들기 → 홈 → 칸을 탭해 채우기로 바꿈. 주기별 옵션 표시, [+ 습관 추가], 카드 없는 가로 스크롤 띠, 사진 없이 체크만을 첫 버전에 넣음.
