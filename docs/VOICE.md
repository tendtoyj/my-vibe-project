## 확정 정보
- **서비스 이름:** 데일리롤
- **한 줄 무드:** 조용히 앨범을 정리해 주는 과묵한 사진관 주인처럼, 있는 그대로를 담담하게.
- **이름 메모:** "롤"은 카메라롤처럼 하루하루 사진이 쌓인다는 뜻으로 쓴다. 한국에서는 "롤"이 게임을 먼저 떠올리게 할 수 있어서, 소개 문구와 로고에서 사진 쪽 의미가 읽히게 한다. 이름 검증(2026-10-10): 같은 이름의 서비스는 확인되지 않았다. 가까운 이름으로 "데일리스 : 감성 포토 다이어리"(iOS)가 있다.

## 1. Voice Summary
조용히 앨범을 정리해 주는 과묵한 사진관 주인처럼 말해요. 판단하거나 부추기지 않고, 칸에 일어난 일을 있는 그대로 짧게 전해요.

## 2. Core Personality Traits

**차분한**
- We are: 서두르지 않고 같은 온도로 말한다. 화면도 조용하지만 정성스럽다.
- We are not: 심심하거나 밋밋한, 의욕 없는 사람.
- This sounds like: "습관을 만들면 여기에 칸이 생겨요."
- This does NOT sound like: "기록됐습니다."

**담백한**
- We are: 짧게 말하되 한 줄 안에 필요한 정보 하나는 담는다.
- We are not: 성의 없는 단답.
- This sounds like: "조깅이 한 칸 채워졌어요."
- This does NOT sound like: "완료."

**정갈한**
- We are: 사진을 가지런히 놓아 줄 뿐, 빈칸을 탓하지 않는다.
- We are not: 깐깐하거나 완벽주의인 사람.
- This sounds like: "이번 달 카드가 만들어졌어요."
- This does NOT sound like: "이번 주 3칸이 비어 있어요. 채워 주세요."

**은근히 다정한**
- We are: 크게 칭찬하는 대신, 모인 것을 짧게 알아봐 준다.
- We are not: 호들갑이나 오지랖, 감성 일기장.
- This sounds like: "이번 주는 사진 4장이 모였어요."
- This does NOT sound like: "오늘도 따뜻한 하루를 소중히 담았어요 ☕"

## 4. Vocabulary Guide

**USE**
- **칸** — 기록의 기본 단위. 평가 대신 칸에 일어난 일을 주어로 말할 때 쓴다.
- **채워졌어요** — 사진이 들어간 순간. "조깅이 한 칸 채워졌어요."
- **모였어요** — 주간·월간으로 모인 것을 말할 때. "사진 4장이 모였어요."
- **만들어졌어요** — 월간 카드처럼 결과물이 생겼을 때. 담담하게 사실만.
- **생겨요** — 다음에 일어날 일을 조용히 알려 줄 때. "여기에 칸이 생겨요."
- **이번 주 / 이번 달** — 기간을 가깝게 가리키는 말. 숫자보다 먼저 쓴다.
- **사진 ○장** — 구체적인 수치로 말한다. "사진 4장".
- **쉬는 날** — 원래 쉬는 날을 부르는 이름. 안 한 날과 구분한다.
- **습관 이름 그대로** — "조깅", "스트레칭"처럼 사용자가 정한 이름을 주어로 쓴다.
- **놓였어요** — 사진이 칸에 자리를 잡았다는 뜻. 칸 단위 표현에 변화를 줄 때.
- **그대로** — 비어 있는 것도 판단 없이 그대로 둔다는 뜻으로.
- **~해요** — 어미는 일상 존댓말 "~해요"로 맞춘다.

**AVOID**
- **달성 / 달성률** — 성적표처럼 평가하는 말이라서. 통계 카드 말투를 쓰지 않는다.
- **연속 / 스트릭 / 끊겼어요** — 끊김을 점수화한다. 놓친 날도 기록의 일부로 둔다.
- **챌린지 / 미션 / 클리어** — 일반 습관 앱 톤. 게임처럼 몰아붙이는 느낌.
- **파이팅 / 화이팅 / Keep going** — 호들갑이고 영어·응원 구호가 섞인다.
- **갓생 등 유행어** — 금방 낡고, 사용자를 한 부류로 규정한다.
- **소중한 / 따뜻한 / 포근한** — 감성 일기장 어휘. 가장 닮기 쉬워서 특히 조심한다.
- **포기 / 실패 / 못 했어요** — 죄책감을 건드린다.
- **분발 / 부족해요** — 사용자를 평가하는 말.
- **빈 칸이에요 / 비어 있어요(먼저 꺼내기)** — 빈 곳을 짚어 탓하는 것처럼 들린다.
- **우쭈쭈 / 최고예요 / 대단해요** — 아기 달래듯 하는 칭찬.
- **~하세요! (명령형)** — 다그치는 말투.
- **완료. / 저장됨.** — 단어 하나로 끝나는 단답.

## 5. Tone Adaptation Rules

**By Context (앱 안 맥락):**

| 맥락 | 톤 조절 | 예시 문구 |
|------|---------|-----------|
| 온보딩 / 첫 화면 | 최소한만 말한다. 설명은 한 줄 이내로 하고 쓰면서 알게 둔다. | "습관 이름과 주기를 정해요." |
| 빈 상태(empty state) | 다음에 일어날 일을 조용히 알려 준다. 재촉하지 않는다. | "습관을 만들면 여기에 칸이 생겨요." |
| 성공/완료 피드백 | 습관 이름을 주어로, 일어난 일만 말한다. 칭찬하거나 이모지를 쓰지 않는다. | "조깅이 한 칸 채워졌어요." |
| 주간 마무리 | 모인 것만 말한다. 비어 있는 칸은 먼저 꺼내지 않는다. | "이번 주는 사진 4장이 모였어요." |
| 월간 공유 카드 | 결과물이 생겼다는 사실만 담백하게 전한다. 장수나 안내를 덧붙이지 않는다. | "이번 달 카드가 만들어졌어요." |
| 에러/안내 | 무엇이 안 됐는지와 다음 행동만 한 줄로. 사과를 늘어놓거나 놀라지 않는다. | "사진을 불러오지 못했어요. 다시 시도해 주세요." |
| 푸시 알림 | 최소화한다. 일요일 밤 주간 마무리만 쓰고, 나머지는 사용자가 켠 것만 보낸다. | "이번 주는 사진 4장이 모였어요." |
| 랜딩/소개 페이지 | 슬로건 같은 한 줄 광고 문구 대신 하는 일을 담담히 설명한다. | "습관마다 사진으로 칸을 채우고, 한 주와 한 달을 돌아봐요." |

규칙: 보이스 속성(차분함·담백함·정갈함·은근한 다정함)은 고정하고, 맥락에 따라 말의 양만 조절한다. 에러에서는 다정함을 줄이고 정갈함을 키워 사실과 다음 행동만 말하고, 빈 상태에서는 다정함을 조금 키워 부담을 덜어 준다. 어느 맥락에서도 이모지·느낌표·평가하는 말은 쓰지 않는다.

## 6. Style Rules
- 존댓말/반말: 일상 존댓말 "~해요"를 기본으로 한다. 지나친 높임("~하시겠습니까")은 쓰지 않는다.
- 문장 길이: 짧되 "~했어요"로 끝나는 완결된 문장으로 쓴다. 단어 하나로 끝내지 않는다.
- 문형: 습관 이름을 주어로 쓴다. "조깅이 한 칸 채워졌어요." (구현 시 "이/가" 조사 처리 필요)
- 이모지·느낌표: 쓰지 않는다. 푸시 알림을 포함해 어디서도 쓰지 않는다.
- 외래어: 가능하면 한글로 쓴다. "챌린지", "스트릭" 같은 말은 쓰지 않는다.
- 숫자: 구체적인 수치를 쓴다. "사진 4장", "한 칸".
- 비어 있는 칸: 먼저 언급하지 않는다. 모인 것 위주로 말한다.
- 설명: 필요한 자리에 한 줄만 둔다. 미리 길게 안내하지 않는다.

## 7. Do's and Don'ts

**Do:**
- 일어난 일을 있는 그대로 말한다. 평가하거나 부추기지 않는다. ("조깅이 한 칸 채워졌어요.")
- 습관 이름을 주어로 쓴다.
- 모인 것을 말한다. 비어 있는 칸은 먼저 꺼내지 않는다. ("이번 주는 사진 4장이 모였어요.")
- 짧되 완결된 문장으로 쓴다.
- 구체적인 수치를 한 가지 담는다.
- 설명은 필요한 자리에만 한 줄 둔다.
- 푸시 알림은 일요일 밤 주간 마무리 정도로 최소화한다.
- 문구를 쓴 뒤 "감성 일기장 말투 같지 않은가?" 하고 점검한다.

**Don't:**
- 다그치는 명령형을 쓰지 않는다. ("지금 바로 시작하세요")
- 죄책감을 건드리지 않는다. ("3일째 비어 있어요. 포기하시는 건가요?")
- 스트릭·연속 기록으로 말하지 않는다.
- 달성률·성적표 같은 통계 카드 말투를 쓰지 않는다.
- 영어·유행어를 섞지 않는다. ("챌린지", "갓생", "Keep going")
- 아기 달래듯 칭찬하지 않는다. ("우쭈쭈 최고예요")
- 이모지와 느낌표를 쓰지 않는다.
- 감성 일기장 어휘를 쓰지 않는다. ("소중한", "따뜻한")
- 단어 하나로 끝내지 않는다. ("완료.", "저장됨.")
