# Setup — 데일리롤

> Vibe Studio · build-spec · 모든 작업 묶음이 같이 쓰는 것
> 작성일: 2026-10-10 · 최종 수정일: 2026-10-10
> 기반: docs/PRODUCT.md, docs/FLOWS.md, docs/DESIGN.md, docs/DECISIONS.md

- **스택:** 프로토타입 — Vite + React + TypeScript + Tailwind CSS · 아이콘 Lucide(`lucide-react`) · 글꼴 Pretendard
  - 이유: 첫 버전에 비밀 키가 필요한 기능이 없고, 눌러보며 흐름을 확인하는 게 목표
- **데이터:** 습관과 채운 칸을 브라우저에 저장(새로고침해도 남게). 가짜로 미리 채운 데이터는 없이 빈 상태에서 시작하고, 사진은 작게 줄여서 저장. 진짜 저장소는 나중에
- **흉내만 낼 것:**
  - 구글 로그인 — [구글로 시작해요]를 누르면 구글 창 없이 바로 로그인된 것으로 처리. 로그인한 뒤엔 새로고침해도 로그인이 유지됨
  - 사진 선택 — 브라우저 선택창으로 대신(앱이 사진첩을 직접 보여주지 않음). [바로 찍기]는 폰에서는 카메라, 컴퓨터에서는 파일 선택창이 열림
  - 계정 — 계정 구분 없이 이 브라우저에 하나만 있음("이미 습관이 있는 계정" 예외는 새로고침 시 홈으로 가는 것으로 대신)
- **이번엔 안 함:** 진짜 구글 로그인, 진짜 저장소, 채운 칸 보기·수정·날짜 수정(→ F2), 같은 날 여러 장, 습관 수정·삭제, 알림 켜기·설정·로그아웃(→ F2), 주간 마무리(→ F2), 월간 공유 카드(→ F3), 카메라 권한 거부 오류 화면 확인
- **옮길 때 다시 볼 것** (Next.js로 옮기면 서버로 가야 하는 것): 구글 로그인, 습관·칸·사진 저장
