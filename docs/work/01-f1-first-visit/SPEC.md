# 01 · F1 첫 한 칸 채우기

> Vibe Studio · build-spec · 작성일: 2026-10-10
> 목표: UI 구현 · 관련 플로우: F1 · 조각 5개
> 정해둔 것: ../SETUP.md

- [x] **1. 프로젝트 준비 + 로그인** (F1 ①)
  - 확인: 첫 화면에 "습관마다 사진으로 칸을 채우고, 한 주와 한 달을 돌아봐요."와 "시작하면 약관·개인정보 동의로 봐요."가 보인다
  - 확인: [구글로 시작해요]를 누르면 습관 만들기 화면이 나온다
  - 확인: 로그인한 뒤 새로고침해도 로그인 화면으로 돌아가지 않는다

- [ ] **2. 습관 만들기** (F1 ②)
  - 확인: 이름이 비어 있으면 [다음]이 눌리지 않는다
  - 확인: [주 N회]를 고르면 "일주일에 몇 번 해요?"와 1~6 칩이 나타나고, [요일 지정]을 고르면 월~일 칩이 나타나며, [매일]은 아래에 아무것도 나타나지 않는다
  - 확인: [요일 지정]을 골라 요일을 하나도 안 고르면 [다음]이 눌리지 않는다
  - 확인: 이름과 주기를 쓰다가 새로고침해도 쓰던 내용이 그대로 있다

- [ ] **3. 홈 — 가로로 긴 띠** (F1 ③)
  - 확인: 이름과 주기를 정하고 [다음]을 누르면 홈이 나오고 "조깅 띠가 만들어졌어요. 칸을 눌러 사진을 채워요."가 보인다
  - 확인: 띠가 가로로 길게 스크롤되고, 처음 열면 오늘 칸이 보이며, 오른쪽은 이번 주 끝까지만 있다
  - 확인: 오늘 이후의 칸은 옅게 보이고 눌러도 아무 일이 없다
  - 확인: 습관이 하나도 없는 상태로 홈에 오면 "습관을 만들면 여기에 칸이 생겨요."와 [+ 습관 추가]가 보인다
  - 확인: [+ 습관 추가]를 누르면 습관 만들기가 나오고, 다시 [다음]을 누르면 홈으로 돌아와 새 띠가 아래에 생긴다

- [ ] **4. 칸 채우기 — 사진 없이 체크만** (F1 ④⑤)
  - 확인: 오늘 칸을 누르면 아래에서 시트가 올라오고 "조깅 · 10월 10일"과 [사진첩에서 고르기] [바로 찍기] "사진 없이 체크만 해요"가 보인다
  - 확인: "사진 없이 체크만 해요"를 누르면 시트가 닫히고, 그 칸에 체크 표시가 보이며 "조깅이 한 칸 체크됐어요."가 보인다
  - 확인: 시트를 닫으면 홈에 그대로 머문다
  - 확인: 쉬는 날(요일 지정에서 고르지 않은 요일) 칸은 중립 톤으로 구분돼 보이고, 눌러도 시트가 열린다
  - 확인: 새로고침해도 체크한 칸이 그대로 있다

- [ ] **5. 칸 채우기 — 사진으로** (F1 ④⑤)
  - 확인: [사진첩에서 고르기]를 누르면 브라우저 사진 선택창이 열리고, 선택창을 닫으면 시트에 그대로 머문다
  - 확인: 사진을 고르면 시트가 닫히고, 그 칸에 사진 썸네일이 보이며 "조깅이 한 칸 채워졌어요."가 보인다
  - 확인: 촬영 날짜가 탭한 칸과 다른 사진을 고르면 촬영 날짜 칸에 놓이고 홈이 그 칸으로 스크롤된다
  - 확인: 촬영 날짜가 없는 사진을 고르면 탭한 칸에 놓인다
  - 확인: 새로고침해도 사진 칸이 그대로 있다
