## F1 · 첫 한 칸 채우기 — "사진첩에 있는 거, 여기 모아볼까?"
> 구분: 첫 방문 · 상태: 기획 완료 · 담당 기능: 습관 만들기, 사진 타일 채우기(첫 칸), 타일 보드(첫 모습)

**목표 순간**
- 진입 동기: 사진첩에 운동·식사 사진이 쌓여 있는데 정리할 곳이 없을 때 처음 들어온다.
- 목표 순간: 내가 만든 습관의 띠에서 칸 하나를 직접 채워 본 홈을 본다.
- 상태 변화: 모름 → 내 습관과 첫 칸이 있는 내 보드를 가짐.

**단계**
| 단계 | 화면 | 기능 | 주 행동 (→ 다음) | 핵심 결정 |
|:--:|------|------|------------------|-----------|
| ① | 로그인 | — | [구글로 시작해요] → ② | 첫 화면이 곧 로그인. 소개는 한 줄, 약관·개인정보 동의도 한 줄로 합침 |
| ② | 습관 만들기 | 습관 만들기 | 이름과 주기를 정하고 [다음] → ③ | 주기를 고르면 그에 맞는 옵션이 아래에 나타남(주 N회 → 횟수, 요일 지정 → 요일). 사진은 요구하지 않음 |
| ③ | 홈 | 타일 보드 | 비어 있는 칸을 탭 → ④ | 습관을 만들면 바로 홈으로 와서 만들어진 걸 보여줌. 띠는 카드에 가두지 않고 가로로 길게 스크롤 |
| ④ | 칸 채우기 (시트) | 사진 타일 채우기 | 사진 선택 또는 체크 → ⑤ | 칸을 탭하면 아래에서 시트가 올라옴. 사진첩에서 고르기 / 바로 찍기 / 사진 없이 체크만. 촬영 날짜로 칸을 자동 배치(D-002) |
| ⑤ | 홈 | 타일 보드 | 첫 칸이 채워진 홈 확인 (목표 순간). 하단 [+ 습관 추가] → ② | 같은 홈이지만 순간이 달라 따로 그림. 습관을 계속 추가할 수 있음 |

**화면**

### ① 로그인
```
 ┌─────────────────────────┐
   데일리롤
   습관마다 사진으로 칸을 채우고,
   한 주와 한 달을 돌아봐요.

   [  구글로 시작해요  ]
   시작하면 약관·개인정보 동의로 봐요.
 └─────────────────────────┘
```
- **역할:** 처음 들어온 사람이 서비스가 하는 일을 한 줄로 알고, 바로 계정을 만든다.
- **핵심 요소:** 서비스 이름, 소개 두 줄, 주요 버튼 하나(구글 로그인), 동의 안내 한 줄. 버튼만 accent로 쓴다.
- **문구:** "습관마다 사진으로 칸을 채우고, 한 주와 한 달을 돌아봐요." / [구글로 시작해요] / "시작하면 약관·개인정보 동의로 봐요." (임시)

### ② 습관 만들기
```
 ┌─────────────────────────┐
   습관 이름과 주기를 정해요.
   [ 조깅____________ ]
   (매일) (●주 N회) (요일 지정)
   일주일에 몇 번 해요?
   (1) (2) (●3) (4) (5) (6)       ← 주 N회를 고르면
   (월)(화)(수)(목)(금)(토)(일)   ← 요일 지정을 고르면
   [        다음        ]
 └─────────────────────────┘
```
- **역할:** 채울 띠 하나를 만든다. 사진은 요구하지 않는다.
- **핵심 요소:** 이름 입력, 주기 칩 세 개(매일 / 주 N회 / 요일 지정). 주 N회를 고르면 횟수 칩 1~6(기본 3), 요일 지정을 고르면 월~일 칩(여러 개 선택)이 아래에 나타나고, 매일은 추가 옵션이 없다. 주요 버튼 [다음].
- **문구:** "습관 이름과 주기를 정해요." / "일주일에 몇 번 해요?"(임시) / [다음]

### ③ 홈 (습관을 만든 직후)
```
                 월 화 수 목 금 토 일 월 화 수 …   ← 가로로 길게 스크롤
 조깅            ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ [▢오늘] ▢ ▢ →
 "조깅 띠가 만들어졌어요. 칸을 눌러 사진을 채워요."

 [ + 습관 추가 ]
```
- **역할:** 방금 만든 습관이 보이고, 칸을 눌러 첫 입력을 시작한다.
- **핵심 요소:** 습관 이름 아래로 칸이 가로로 이어지는 띠. 카드나 테두리에 가두지 않고 화면 끝까지 이어지며, 가로로 길게 스크롤된다. 맨 위에 날짜(요일) 줄이 있고 모든 습관이 같은 날짜 열을 공유해 함께 스크롤된다. 시간은 왼쪽에서 오른쪽으로 흐르고, 처음 열면 오늘 칸이 보이게 스크롤된다. 왼쪽(과거)으로는 길게 이어지고 오른쪽은 이번 주 끝까지만 있다. 오늘 이후 칸은 옅다. 마지막 띠 바로 아래에 [+ 습관 추가]가 있다.
- **문구:** "조깅 띠가 만들어졌어요. 칸을 눌러 사진을 채워요." / [+ 습관 추가](임시)

### ④ 칸 채우기 (시트)
```
 ┌──────────────────────┐
   조깅 · 10월 10일
   [ 사진첩에서 고르기 ]
   [ 바로 찍기 ]
   사진 없이 체크만 해요
 └──────────────────────┘
```
- **역할:** 탭한 칸을 사진 또는 체크로 채운다.
- **핵심 요소:** 습관 이름과 날짜, 주요 버튼 [사진첩에서 고르기], 보조 버튼 [바로 찍기], 텍스트 링크 "사진 없이 체크만 해요". 사진첩은 격자로 보여주지 않고 브라우저 선택창이 열린다. 홈 위에 올라오는 시트다.
- **문구:** [사진첩에서 고르기] / [바로 찍기] / "사진 없이 체크만 해요" (임시)

### ⑤ 홈 (첫 칸이 채워진 뒤)
```
                 월 화 수 목 금 토 일 월 화 수 …
 조깅            ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ [▣오늘] ▢ ▢ →
 "조깅이 한 칸 채워졌어요."

 [ + 습관 추가 ]
```
- **역할:** 내가 채운 칸이 띠에 놓인 걸 본다. 서비스의 핵심 화면(습관 × 기간 보드)의 첫 모습.
- **핵심 요소:** ③과 같은 홈. 채워진 칸은 사진 썸네일(체크만이면 체크 표시), 나머지는 중립 톤(오류 색 금지). 채운 칸은 홈이 그 칸으로 스크롤되어 보인다. 습관이 많아지면 띠가 세로로 쌓이고 홈이 세로로 스크롤된다. [+ 습관 추가]는 항상 마지막 띠 바로 아래.
- **문구:** "조깅이 한 칸 채워졌어요." / 체크만이면 "조깅이 한 칸 체크됐어요."(임시)

**화면 상태**
| 화면 | 빈 | 로딩 | 오류 |
|------|----|------|------|
| ① 로그인 | — | 버튼이 눌린 상태로 대기 | "로그인하지 못했어요. 다시 시도해 주세요." |
| ② 습관 만들기 | — | — | "습관을 저장하지 못했어요. 다시 시도해 주세요." (이름이 비어 있거나 요일을 하나도 안 골랐으면 [다음]만 비활성, 문구는 없음) |
| ③⑤ 홈 | 습관이 하나도 없을 때 — "습관을 만들면 여기에 칸이 생겨요." / 습관을 만든 직후 — "조깅 띠가 만들어졌어요. 칸을 눌러 사진을 채워요." | 칸 자리만 옅게 보임 | "보드를 불러오지 못했어요. 다시 시도해 주세요." |
| ④ 칸 채우기 (시트) | — | 사진 처리 중에는 작은 진행 표시 | 카메라 권한 거부 — "카메라를 열 수 없어요. 사진첩에서 골라 주세요." / 불러오기 실패 — "사진을 불러오지 못했어요. 다시 시도해 주세요." / 저장 실패 — "칸을 저장하지 못했어요. 다시 시도해 주세요." |

**예외**
| 단계 | 상황 | 어떻게 동작하나 |
|:--:|------|----------------|
| ① | 구글 창을 닫음 | ①에 그대로 머문다 |
| ① | 이미 습관이 있는 계정으로 로그인 | ②를 건너뛰고 홈으로 간다 |
| ② | 쓰다가 나감 | 이름과 주기를 임시 저장하고, 돌아오면 이어서 쓴다 |
| ② | 이름이 같은 습관이 이미 있음 | 그대로 허용한다 |
| ③ | ②를 마치지 않고 홈으로 옴 | 빈 홈을 보여주고 [+ 습관 추가]를 둔다 |
| ③ | 오늘 이후의 칸을 탭 | 이번 주 끝까지의 칸은 옅게 보이고 탭은 안 된다 |
| ③ | 쉬는 날 칸을 탭 | 중립 톤으로 구분해 보여주되, 탭하면 시트가 열린다(사진이 우선) |
| ④ | 시트를 닫음 | 홈에 그대로 머문다 |
| ④ | 사진 선택창을 닫음 | 시트에 그대로 머문다 |
| ④ | 사진의 촬영 날짜가 탭한 칸과 다름 | 촬영 날짜 칸에 놓고 홈이 그 칸으로 스크롤된다(D-002) |
| ④ | 사진에 촬영 날짜가 없음 | 탭한 칸에 놓는다 |
| ④ | 이미 채워진 칸을 탭 | F2에서 그린다 |
| ⑤ | 습관이 많아짐 | 띠가 세로로 쌓이고 홈이 세로로 스크롤된다. [+]는 항상 마지막 띠 바로 아래 |
| ⑤ | [+ 습관 추가] 탭 | ②로 간다. [다음] 후에는 홈으로 돌아와 새 띠가 아래에 생긴다 |

**첫 버전 범위**
- 넣음: 구글 로그인, 습관 만들기(주기별 옵션), 홈의 가로 스크롤 띠(날짜 열 공유), 칸 채우기(사진첩 / 바로 찍기 / 사진 없이 체크만), [+ 습관 추가]
- 나중에: 채운 칸 보기·수정·날짜 수정(→ F2), 같은 날 여러 장, 습관 수정·삭제, 알림 켜기·설정·로그아웃(→ F2), 주간 마무리(→ F2)

**건너뛴 기본값:** 주 N회의 N은 1~6, 기본 3(7회는 매일과 같음). 홈 첫 화면은 오늘 칸이 보이게 스크롤. 사진 날짜가 탭한 칸과 달라도 촬영 날짜를 따름. 계정 화면에 약관·개인정보 동의 한 줄.

**변경 기록**
- 2026-10-10 기획 완료.
- 2026-10-10 흐름 수정: 습관을 만든 뒤 사진 입력까지 묶던 단계를 풀어, 습관 만들기 → 홈 → 칸을 탭해 채우기로 바꿈. 주기별 옵션 표시, [+ 습관 추가], 카드 없는 가로 스크롤 띠, 사진 없이 체크만을 첫 버전에 넣음.

## F2 · 일요일 밤 주간 마무리 — "이번 주 뭐 했더라"
> 구분: 다시 오기 · 상태: 후보 · 담당 기능: 주간 마무리, 사진 타일 채우기(몰아서·날짜 수정), 타일 보드(쌓인 상태)

일요일 밤에 돌아와 사진을 몰아서 채우고 한 주를 마무리함. 아직 그리지 않음.

> 구분: 기능 · 상태: 후보 · 담당 기능: 월간 공유 카드

한 달 치 보드를 공유용 이미지로 만듦. 아직 그리지 않음.
